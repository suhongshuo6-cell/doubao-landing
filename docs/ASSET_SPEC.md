# 角色模型资产规格（ASSET_SPEC）

这份文档是给**生成 3D 模型的那一步**看的。按这里的参数导出，模型丢进
`public/models/doubao.glb` 就能被页面直接接住，不需要改任何代码。

页面有两条资产路径，运行时会自动探测：

| 路径 | 触发条件 | 说明 |
|---|---|---|
| **A · 真 3D** | `public/models/doubao.glb` 存在 | 走 `ModelCharacter`，PBR 材质 + 三点布光 + 捏脸形变注入 |
| **B · 2.5D 立绘** | 没有 glb | 走 `ImageRigCharacter`，用 `public/img/` 里的分层立绘做伪立体 |

两条路径实现同一个 `Character` 接口（`load / pinch / setFraming / setPointer / update / dispose`），
所以**先上线路径 B、之后随时补上模型升级到路径 A**，页面零改动。

---

## 0. 路径 B 的立绘素材规格（**这一条最重要，且当前素材不满足**）

页面要做的是「**摄影机在轨道上滑行**，从脸一路下移到赤足」——
一句话里最关键的是**连续**两个字。它对立绘素材提出一个硬要求：

> **需要一张连续的高分辨率全身图**，让相机能在**同一张照片内部**连续推拉。
> 建议 ≥ 2560×1440（4K 更好），竖构图能留出更多纵向余量。

### 为什么"每个部位一张特写"这条路走不通

我按「每个身体部位一张特写 + 3 张全身图」做了离线取景验证
（`tools/preview_frames.py`，与 shader 同一套取景数学），结果是三种过渡方式都不成立：

| 过渡方式 | 实测结果 |
|---|---|
| 线性交叉淡化 | **双重曝光**。脸叠在围巾上、大腿叠在腰上、巨大的一只脚叠在小小一个全身像上 |
| 焦点切换（窄窗口 + 双侧虚焦） | 好一些，但**重影仍然可见**——因为相邻两张的尺度差是 3~10 倍 |
| 硬切（完全不重叠） | 干净锐利、零重影，**但读起来是"照片集"而不是"一次运镜"** |

根因很简单：这几张特写是**各自独立的镜头**，彼此没有共享的尺度参照。
任何淡化都只是把两个不同尺度、不同构图的东西叠在一起。

### 结论与三个可选方案

| 方案 | 怎么做 | 结果 |
|---|---|---|
| **A（推荐）** | 给一张 ≥2560×1440 的**连续全身图** | 真正的连续运镜：相机在同一张照片里 dolly，特写与全身是同一张图的裁切，天然对齐 |
| B | 保留现在的素材，把语言从"运镜"改成"分镜" | 硬切 + 干净锐利的分镜集，可看、有编辑感，但不是规格要的"轨道滑行" |
| C | 改用路径 A（`doubao.glb`） | 唯一同时满足「连续运镜 + 任意角度 + 高清 + 高光材质」的方案 |

> **已落地的最终决定（2026-10）**：当前版本按 **B** 交付，并把 B 做到极致 ——
> 硬切 + 焦点切换 + 每镜内部推近 + 双层视差 + 全身三视图转身
> （实现见 `src/three/imageRigCharacter.ts` / `src/three/plateShader.ts`，
> 抠像见 `tools/make_mattes.py`）。A 与 C 仍是零改动升级路径：
> 放 `doubao.glb` 进 `public/models/` 自动切 C；补一张 ≥2560×1440 的连续全身图后可改成 A。

**另外**：5 张特写都只有正面一个视角，所以横向鼠标的 ±10° yaw
在特写段落**做不出真正的转身**（只有视差位移）；yaw 只有到了全身段
（`doubao_front/side/back` 三视图）才成立。这与规格 6.6 "用于在全身段落展示侧/背面的服装与体态"一致。

## 1. 坐标系与朝向（最容易错，请严格照做）

| 项 | 要求 | 备注 |
|---|---|---|
| 上方向 | **Y-up** | 不要 Z-up。导出的预览里"天空"应该在 +Y |
| 原点 | **双脚脚底中心**，即 `y = 0` 在地面 | 原点跑到腰部会导致取景整体下移半个身位 |
| 朝向 | **面朝 +Z** | 相机会从 +Z 方向看过来。面朝 -Z 会导致全程背对观众 |
| 水平居中 | 身体中轴在 `x = 0`、`z = 0` 附近 | 页面自己也会重新居中，但导出时就正回来更稳 |
| 单位 | 米 | 身高 1.65–1.75 之间最合适 |

> 页面会做一次**归一化**：量包围盒 → 等比缩放到 1.72m → 脚底对齐 `y = 0` → 水平居中。
> 所以缩放进错了也不会崩，但**朝向错了它救不回来**（朝 -Z 就是背对观众一整页）。

## 2. 姿态

- 自然站立，**重心落在一条腿上**（另一条腿略微放松），不要立正的对称站姿
- 双臂自然下垂或轻搭在体侧/胯部，**不要大幅张开**：大特写时手臂会顶出画面
- 头部朝正前方，视线与相机大致齐平，表情放松
- **不需要 T-pose**。这是展示用模型，不是绑定用模型

## 3. 着装（必须与参考图完全一致，不允许改动）

| 部位 | 内容 |
|---|---|
| 上衣 | 黑色短袖短上衣（crop top），下摆到肋骨下缘 |
| 围巾 | 红色针织长围巾，绕颈一周、两段垂在胸前，末端有流苏 |
| 下装 | 黑色紧身短裤 |
| 足部 | 光脚，无鞋无袜 |
| 发型 | 黑色短发，齐下巴长度，有刘海 |

> 页面红线的第 4 条：镜头语言是"电影取景巡礼"，不做身体凝视、不做暗示性取景。
> 模型请保持**完整着装**，不要为了"好看"减少布料或改短版型。

## 4. 贴图

| 项 | 要求 |
|---|---|
| 分辨率 | **2K（2048×2048）**，皮肤区域需要更清晰的可以给 4K 单独一张 |
| 格式 | **KTX2 / UASTC**（`KTX2Loader` 已在页面里接好，转码器自托管在 `public/basis/`） |
| 通道 | baseColor、normal、roughness（金属度基本为 0，可不给） |
| 色彩空间 | baseColor 必须是 **sRGB**；normal/roughness 必须是 **Linear** |
| 打包 | 建议 baseColor 单张，roughness/normal 各一张；避免 6–7 个材质槽 |

导出的 `.ktx2` 用 `toktx --encode uastc` 或 gltf-transform 的
`gltf-transform etc1s` / `uastc` 命令都可以。

## 5. 拓扑与性能预算

| 项 | 上限 | 理由 |
|---|---|---|
| 三角面 | **≤ 60k** | 中端笔电集显要稳 60fps；再高收益很小、代价很大 |
| 材质槽 | ≤ 4 | 每个材质槽 = 一次额外 draw call；页面预算 `render.calls < 40` |
| 文件体积 | **< 4MB**（含贴图） | 首屏可交互 < 1.5s 的一部分 |
| 骨骼 | **不需要** | 页面用程序化运镜，不做骨骼动画 |

压缩方式二选一（页面都支持）：

```bash
# 顶点用 Draco + 贴图用 KTX2
gltf-transform draco in.glb doubao.glb
gltf-transform uastc in.glb doubao.glb
```

## 6. 可选的 blendshape（有则更自然，没有也不影响）

捏脸交互会自动寻找下面这些形变目标名，找到就同步驱动（强度与顶点形变叠加）：

- 挤压类：`faceSqueeze` / `cheekSqueeze` / `squint` / `mouthPress`
- 鼓起类：`cheekPuff` / `cheekPuffLeft` / `cheekPuffRight` / `noseSquish`

强度范围 0–1，由页面的弹簧给出（按下约 120ms 到位，松开约 260ms 回弹、约 8% 过冲）。

## 7. 面数分配建议

| 部位 | 建议面数 |
|---|---|
| 头部 / 面部 | 25k–35k（面部是全程被看得最多的地方，成本要花在这里） |
| 头发 | 8k–14k |
| 躯干 + 四肢 | 12k–18k |
| 服装（上衣/短裤/围巾） | 6k–10k |

面部请保证：**眼睛、鼻翼、唇部有足够密度的环形布线**。
捏脸形变是沿法线压入，布线太粗会看到明显的折角。

## 8. 自检清单（导出前逐条过一遍）

- [ ] 在预览器里加一个 `y = 0` 的网格，脚底正好踩在网格上
- [ ] 从 +Z 看过去是正面
- [ ] 总身高在 1.65–1.75m 之间
- [ ] 目视检查没有穿模：围巾不穿进脖子、手臂不穿进身体
- [ ] 三角面数 ≤ 60k
- [ ] 贴图是 KTX2/UASTC，baseColor 是 sRGB
- [ ] 文件总大小 < 4MB
- [ ] 拖进 `public/models/doubao.glb`，刷新页面，URL 上加 `?character=model` 强制走路径 A

## 9. 调试开关

| URL 参数 | 作用 |
|---|---|
| `?character=model` | 强制走真 3D 路径（glb 不存在会回退到立绘） |
| `?character=imageRig` | 强制走 2.5D 立绘路径 |
| `?character=probe` | 强制走探针胶囊体（排查相机取景时用） |
| `?nointro=1` | 跳过开场推近，直接停在最终取景 |

浏览器控制台里还有 `window.__DOUBAO`：

```js
__DOUBAO.state()      // { framing, node, kind, ready, renderScale, drawCalls }
__DOUBAO.goTo(0.92)   // 跳到"全身"取景节点
__DOUBAO.killIntro()  // 立刻结束开场动画
```
